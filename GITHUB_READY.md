## 🚀 How to Push to GitHub (5 Steps)

### Step 1: Create Repository on GitHub
```bash
1. Go to https://github.com/new
2. Repository name: Alexandria
3. Description: Knowledge Management System with SSH Support
4. Visibility: Public (or Private)
5. Do NOT init with README/license/.gitignore
6. Click "Create repository"
```

### Step 2: Copy the Remote URL
GitHub will show you:
```
https://github.com/YOUR-USERNAME/Alexandria.git
```

### Step 3: Add Remote
```bash
cd /home/gabrielle/Documents/Alexandria
git remote add origin https://github.com/YOUR-USERNAME/Alexandria.git
```

### Step 4: Rename Branch & Push
```bash
git branch -M main
git push -u origin main
```

### Step 5: Authenticate
- **GitHub Username**: your-username
- **Personal Access Token**: (create in GitHub Settings > Developer settings)
